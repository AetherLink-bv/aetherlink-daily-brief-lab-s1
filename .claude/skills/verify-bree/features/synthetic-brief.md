# Synthetic Daily Brief

## Sub-features

Schema validation, HTML escaping, six content sections, provenance, OPEN, and CONFLICT.

## How to get to it (user POV)

Run `npm run brief:sample`, then open `out/latest.html`.

## Driving it with the repository commands

Run the five targeted test scripts, `npm run eval`, and `npm run brief:sample`.

## Gotchas

The synthetic path proves no Jira or Vertex access. The full local suite remains OPEN by workshop resource policy.
