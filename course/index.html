Keep one source boundary

The synthetic adapter supports tests. The live adapter permits one exact approved read tool. Bree receives no shell, file-write, messaging, or ticket-update tool.

Keep proof separate

Synthetic tests prove the contract. The preflight proves local configuration only. A private live run proves authentication and source access. None proves the others.

Fresh commands are evidence. Stored live data is not required.

Missing

Generate Bree's verification skill

/create-verification-skill maps actual repository commands. It stays DRAFT until launch, doctor, drive, evidence, and cleanup complete for one synthetic journey.

Prove recovery, then propose the daily trigger

Run previous and current versions in temporary worktrees. Propose a local daily command with owner, logs, and rollback. Do not install a scheduler until the participant approves it.
