What this lab builds

One local agenda item becomes one visible decision line.

Start small before lunch

A1 turns sample/calendar-item.sample.json into one line: time, title, and the decision you chose. The test is red before src/mini.ts exists and green after the smallest implementation.

npm run mini

The boundary stays visible

The application uses local fixtures. It receives no network, shell, or write capability. Missing input becomes OPEN. Conflicting input becomes CONFLICT.

02

Choose the user and decision

A useful brief helps one person decide one thing.

Write an observable intent

Name the reader, the morning decision, one visible line, and the hard boundary. Update the intent and the matching fixture fields.

/grilling Challenge whether my chosen user, decision, and boundary are observable. Ask one question at a time. Do not edit files.

Prove the first path

The fixture contains one agenda item. The mini command prints one line. The exact shape makes the result easy to inspect.

<start> <title> — decide: <decision>
03

Schema, design, and plan

Define the contract before adding the renderer or tool.

Red, then green

A2 writes test/schema.test.ts before src/brief.ts. The schema covers ordinary input, missing input, and conflicts.

npm run test:schema

Plan in read-only mode

A3 starts in plan mode. Every step names a root-relative path, proof command, and reversible rollback. After approval, return to manual mode and save only the accepted documents.

Keep one source boundary

The design permits exactly one readAgenda tool. It reads one local JSON fixture and cannot write, start a shell, or call a network service.

04

Build the visible result

The accepted plan becomes a tested HTML brief.

Render local data

A4 writes the renderer test first. The implementation escapes untrusted text and writes out/latest.html.

npm run test:render
npm run brief:sample
open out/latest.html

Build the local agent path

A5 connects an instruction, a controlled test-model choice, one readAgenda call, and an answer. The proof covers the tool contract, not model quality.

npm run test:tool

Name source errors

A fixture without start must produce an explicit source error. The agent receives no network, shell, or write capability.

05

Evaluate and deliver locally

Fresh commands are evidence. Claims are not.

Three cases

Ordinary

Produce the expected decision line.

Missing

Return OPEN. Invent nothing.

Conflict

Return CONFLICT. Choose nothing silently.

npm run eval

Run two temporary worktrees

A6 runs the accepted A5 commit and the new A6 commit in separate detached worktrees. Both must install, test, and render locally.

git worktree add --detach ../daily-brief-previous HEAD^
git worktree add --detach ../daily-brief-current HEAD

Prove the previous version still runs

The previous worktree is the recovery result. Compare its page with the current page. Remove both temporary worktrees after the proof.
