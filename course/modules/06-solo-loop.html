The SOLO loop

Build all seven steps with Claude Code, inspect each result, and keep every decision human-owned.

Seven builds with a review after each result

SOLO.md guides one person through seven builds with their own GitHub, Linear, and Notion. Each step has one Claude Code prompt and ends with evidence you inspect.

The current prompt, checkpoint, and proof command form the contract. Historical step-* tags belong to an older lesson and are not acceptance evidence for this route.

1
Plan: intent (15 min)

Claude Code interviews you one question at a time. You cut.

2
Design: spec and contract, test first (25 min)

Quote the PDFs, write the failing test, then the code.

3
Build, in plan mode: one decision, a plan with proof (15 min)

Claude Code in plan mode: read-only until you accept.

4
Build: render the sample (25 min)

The first artifact: out/latest.html, no API key needed.

5
Build: the loop and one read-only tool (20 min)

Build the agent and one tool, then wire the live and sample routes. The live run needs credentials.

6
Test: record the evidence (15 min)

Three commands, exit codes, one screenshot, one reviewer.

7
Deploy: review the gate and prepare the schedule (15 min)

Decide the gate, then open the pull request and keep the schedule inactive.

Review your own diff after every assignment

git status --short

PLAIN ENGLISH

Inspect the scope. List every changed and untracked path.

Check the size. Confirm that only the accepted assignment changed.

Read the change. Inspect every line before you commit it.

🔍
Your evidence is the review aid

Step 5 asks Claude Code to build agent.ts, sources.ts, and the live path in main.ts. Accept it only after its tests and sample route work.

The live run: read the log, not just the page

Step 5 has a live run only if you have read-only credentials. Without them, the sample route still works and the live check stays OPEN.

SOLO.md 
With credentials, run `npm run brief 2> run.log` to make `run.log`.
Claude Code builds and runs checks. The built brief-agent gets no shell or write tools. Inspect the tool trace. Missing credentials leave live evidence OPEN.
PLAIN ENGLISH

Run the real brief and send its diagnostic output (2>, the error stream) into a file called run.log.

Claude Code does the building and the checking. The agent you build can only read. Read its tool calls in the log. No credentials means the live check is OPEN, not failed.

The sharpest check in the lab: trace each factual claim in the brief to a tool call in run.log. A sentence with no matching tool call came from nowhere.

Where the trail ends: back at the start

README.md 
Maintain is not an assignment. OPEN items in `docs/gate.md` become a new `intent.md`.
PLAIN ENGLISH

The last stage of the cycle, Maintain, is not one of your seven assignments.

Whatever the gate left OPEN is where the next round of intent starts. The route is a circle, not a line.

Before that, finish the handoff. A reviewer reruns one command. A prepared schedule stays inactive until you approve activation. The pull request stays unmerged until a person accepts the result.

💡
Documents are living, not paperwork

AGENTS.md rule 6: "when evidence changes the intent, the spec or the plan, go back and change that document before continuing." If your AI assistant patches code to match a surprise without updating the document above it, the documents stop being true, and the next session reads a lie.
