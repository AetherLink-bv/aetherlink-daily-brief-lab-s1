Connect only Jira, read-only

Before A5, close the first session and connect Jira once, in this project folder. Then log in with /mcp and switch off every tool that can change something.

claude mcp add --transport http jira https://mcpjira.kazan.ai.worldline-solutions.com/mcp
claude --setting-sources project,user --permission-mode default --no-chrome
/mcp

The SDK loads only the servers of this folder, allows one exact read tool and denies every other tool. The host writes only validated private HTML.

Keep proof separate

Synthetic tests prove the contract. The preflight proves local configuration only. A private live run proves authentication and source access. None proves the others.
