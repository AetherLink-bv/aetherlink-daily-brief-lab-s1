# ADR-001 — Host owns validation and writing

Status: Accepted 2026-11-21.

The agent may request data through one approved read-only tool. It returns a candidate `DailyBrief` only. The host validates the complete contract, accepts only source IDs present in the structured tool result, renders escaped HTML, and writes the private artifact with mode `0600`.

This keeps connector access read-only and prevents the model from acquiring shell or file-write capability.
